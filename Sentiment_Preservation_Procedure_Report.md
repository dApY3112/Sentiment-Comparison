# Sentiment Preservation Evaluation for Vietnamese-English Medical Translation

## Introduction

This project evaluates Vietnamese-to-English medical translation quality with a specific focus on **Sentiment Preservation**. The project compares translations generated by ChatGPT and Gemini and checks whether each English translation preserves the emotional meaning of the original Vietnamese medical sentence.

The main objective is to determine whether the translated sentence keeps the same patient emotion, urgency, and clinical tone as the Vietnamese source. In medical translation, this is important because emotion can carry clinical meaning. For example, a patient saying they are "very afraid," "in severe pain," or "relieved after treatment" gives information about anxiety, severity, recovery, and patient experience. If a translation weakens or changes this emotion, the English reader may misunderstand the seriousness of the patient's condition.

The project input includes Vietnamese medical-domain source sentences, English human/reference translations when available, and English translations generated by ChatGPT and Gemini. In this repository, the MedEV dataset is prepared into `data/medev_test.csv` with `id`, `source_vi`, and `reference_en` columns.

The project output includes translated English sentences, translation-quality scores, sentiment labels, Sentiment Preservation scores, manually reviewed examples, and final conclusions about which translation system better preserves patient sentiment.

## Dataset Preparation

The first step is to collect Vietnamese medical-domain sentences. These sentences should represent realistic medical communication, including patient symptoms, pain, side effects, treatment response, diagnosis, doctor consultation, emergency situations, recovery, fear, hope, and anxiety.

In this repository, dataset preparation is handled by `01_prepare_data.ipynb`. The notebook loads the MedEV dataset from Hugging Face and prepares a clean evaluation file. In the current project setup, the MedEV test split is loaded as a single `text` column. The notebook treats the first half of the test split as English reference translations and the second half as Vietnamese source sentences. It then aligns the two halves by index.

The prepared dataset contains:

| Column | Meaning |
|---|---|
| `id` | Unique sentence identifier |
| `source_vi` | Vietnamese medical source sentence |
| `reference_en` | English human/reference translation |

The output of this step is:

```text
data/medev_test.csv
```

If a new dataset is used, the same structure should be followed. Each row should contain one Vietnamese sentence and, if available, one English human/reference translation. If no human reference is available, Sentiment Preservation can still be measured, but traditional translation metrics such as BLEU, chrF++, and TER cannot be calculated reliably.

## Translation Procedure

The second step is to generate English translations from the Vietnamese source sentences. In this repository, translation is handled by `02_translate.ipynb`.

The notebook uses two translation models:

| Model Name in Report | API Model |
|---|---|
| ChatGPT / GPT | `openai/gpt-5.2` |
| Gemini | `google/gemini-2.5-flash` |

Both models are asked to translate the Vietnamese medical sentence into natural and accurate English. The prompt instructs the model to return only the translated sentence without explanation. This keeps the output clean and easy to evaluate.

The translation procedure is:

1. Load `data/medev_test.csv`.
2. Read each Vietnamese source sentence from `source_vi`.
3. Send the sentence to ChatGPT.
4. Save the ChatGPT English output.
5. Send the same sentence to Gemini.
6. Save the Gemini English output.
7. Resume from existing output files if translation was interrupted.
8. Retry failed rows when possible.
9. Remove or mark rows with API errors before evaluation.

The outputs are:

```text
outputs_medev/translations_gpt.csv
outputs_medev/translations_gemini.csv
```

Each translation file contains the source sentence, reference translation, generated English translation, and model name.

## Building the Evaluation Table

After translation, the next step is to build one aligned evaluation table. This table should combine the Vietnamese source sentence, English reference translation, GPT translation, and Gemini translation.

The ideal evaluation table contains:

| Column | Meaning |
|---|---|
| `id` | Sentence identifier |
| `source_vi` | Vietnamese source sentence |
| `reference_en` | Human/reference English translation |
| `gpt_en` | English translation generated by GPT |
| `gemini_en` | English translation generated by Gemini |

This table is important because Sentiment Preservation must be evaluated row by row. The GPT and Gemini translations must be compared against the same Vietnamese source sentence.

Rows with failed translations, empty outputs, or API error messages should be excluded from final scoring because they would distort the comparison.

## Sentiment Preservation Measurement

Sentiment Preservation means that the emotional meaning of the Vietnamese source sentence is maintained in the English translation. The translation should preserve whether the source sentence is positive, negative, neutral, anxious, fearful, painful, hopeful, or relieved.

In this project, the main sentiment model is:

```text
cardiffnlp/twitter-xlm-roberta-base-sentiment
```

This model is used in `05_sentiment_preservation.ipynb` to classify sentiment for:

| Text Column | Description |
|---|---|
| `source_vi` | Vietnamese source sentence |
| `reference_en` | English reference translation |
| `gpt_en` | GPT translation |
| `gemini_en` | Gemini translation |

The model produces sentiment labels such as:

```text
negative
neutral
positive
```

The basic comparison is simple:

1. Identify the sentiment of the Vietnamese source sentence.
2. Identify the sentiment of the GPT English translation.
3. Identify the sentiment of the Gemini English translation.
4. Compare each translation label with the Vietnamese source label.
5. Count whether the sentiment was preserved.

For automatic scoring, the strict score can be:

| Condition | Score |
|---|---:|
| Source sentiment and translation sentiment match exactly | 1 |
| Source sentiment and translation sentiment do not match | 0 |

The strict preservation accuracy is:

```text
Sentiment Preservation Accuracy = Number of matched sentiment labels / Total compared rows
```

For manual review, a more flexible score can be used:

| Condition | Score |
|---|---:|
| Sentiment is fully preserved | 1.0 |
| Sentiment is slightly shifted but still close | 0.5 |
| Sentiment is clearly changed | 0.0 |

This graded score is useful because medical emotion is often more complex than three labels. For example, "very afraid" and "concerned" are both negative, but they do not have the same anxiety level.

### Small Scoring Example

| Vietnamese Source | English Translation | Interpretation | Score |
|---|---|---|---:|
| Tôi rất sợ kết quả sinh thiết ngày mai. | I am very afraid of tomorrow's biopsy result. | Fear is fully preserved. | 1.0 |
| Tôi rất sợ kết quả sinh thiết ngày mai. | I am a little concerned about tomorrow's biopsy result. | Emotion is weakened but still close. | 0.5 |
| Tôi rất sợ kết quả sinh thiết ngày mai. | I am calm about tomorrow's biopsy result. | Emotion is changed. | 0.0 |

## Justification for XLM-RoBERTa

XLM-RoBERTa is a multilingual transformer model based on the RoBERTa architecture. It was trained on large-scale multilingual text and is designed to work across many languages. This makes it suitable for a project that compares Vietnamese source sentences with English translations.

The model is useful for this project because it can process both Vietnamese and English in a shared multilingual framework. This is important because Sentiment Preservation requires cross-lingual comparison. The project needs to know whether a Vietnamese sentence and its English translation express the same sentiment.

XLM-RoBERTa can be used for sentiment classification because sentiment-specific versions of the model have been fine-tuned to predict labels such as negative, neutral, and positive. In this repository, the model `cardiffnlp/twitter-xlm-roberta-base-sentiment` is used for this purpose.

Compared with manual-only evaluation, XLM-RoBERTa has several advantages:

| Advantage | Explanation |
|---|---|
| Scalability | It can label thousands of sentences quickly. |
| Consistency | It applies the same decision process to every row. |
| Reproducibility | The same model can be rerun on the same data. |
| Cross-lingual support | It can process both Vietnamese and English. |
| Reviewer efficiency | Human reviewers can focus on difficult cases instead of every row. |

However, XLM-RoBERTa also has limitations. It is not a medical-specialist model, and it may not fully understand clinical urgency, implied anxiety, or subtle emotional differences. Therefore, manual review by Quynh remains necessary, especially for sentences involving severe symptoms, emergency situations, diagnosis anxiety, cancer-related language, side effects, and mixed emotions.

## Why It Fits Medical Translation

XLM-RoBERTa is suitable for this project because medical translation often involves emotionally sensitive content. Patients may describe pain, fear, uncertainty, disappointment, relief, or hope. These emotions are part of the meaning of the sentence.

A small sentiment shift can change how the patient's condition is perceived. For example, translating "I am terrified" as "I am concerned" weakens the anxiety level. Translating "severe pain" as "discomfort" reduces the perceived seriousness of the symptom. Translating "I feel relieved" as "I feel okay" may remove an important sign of emotional recovery.

Because XLM-RoBERTa supports multiple languages, it is useful for comparing Vietnamese source sentences with English translations. The same model family can be applied to both sides of the translation pair, which makes the evaluation more consistent.

Still, medical terminology and patient emotion can be complex. Some sentences are emotionally indirect. For example, "I cannot sleep because I keep thinking about tomorrow's biopsy result" expresses anxiety even though it does not directly say "I am anxious." A sentiment model may classify such a sentence as neutral if the emotional cue is subtle. This is why the best evaluation combines automatic classification with manual review.

## Limitations

This project has several limitations that should be clearly reported.

First, sentiment labels such as negative, neutral, and positive are broad. They do not fully capture detailed emotions such as fear, panic, relief, uncertainty, hope, frustration, or disappointment.

Second, a translation may preserve sentiment but still contain a medical error. For example, `abdominal pain` and `stomach pain` may have different clinical meanings depending on context.

Third, a translation may be medically accurate but emotionally shifted. For example, `terrified` and `worried` both express negative sentiment, but they do not express the same anxiety level.

Fourth, XLM-RoBERTa is multilingual, but it is not specifically trained for medical sentiment in Vietnamese-English translation. Therefore, it may misclassify rare clinical phrases, implied emotions, or highly technical sentences.

Fifth, automatic evaluation may be affected by class imbalance. If most source sentences are neutral, overall accuracy may look high even if the model performs poorly on positive or negative emotional cases.

For these reasons, automatic Sentiment Preservation scores should be interpreted together with manual review by Quynh.

## Conclusion

This project provides an end-to-end procedure for evaluating Vietnamese-to-English medical translation with a focus on Sentiment Preservation. The workflow begins by preparing Vietnamese medical sentences and English reference translations, then generating English translations with ChatGPT and Gemini. The project then builds an aligned evaluation table and applies XLM-RoBERTa to classify sentiment in the Vietnamese source and English translations.

Sentiment Preservation is measured by comparing the sentiment label of each Vietnamese source sentence with the sentiment label of each English translation. A strict automatic score can count exact label matches, while a graded manual score can capture partial shifts in emotional intensity.

The final evaluation should combine automatic scoring with manual review. XLM-RoBERTa provides scalable and consistent sentiment classification, while Quynh's review is necessary for medically sensitive, emotionally subtle, or clinically ambiguous examples. Together, these methods give a stronger and more trustworthy assessment of whether GPT and Gemini preserve patient sentiment in medical translation.
